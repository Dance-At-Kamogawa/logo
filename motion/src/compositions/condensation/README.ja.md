# Condensation — 窓の結露

雨の京都の夜、結露した窓ガラス越しに見る。ガラスの向こうにはピントの外れた街の灯り（暖色・寒色の玉ボケ、アクアのアクセント）と DAK ロゴ。曇ったガラスは微細な水滴で光を拡散し、背景もロゴもぼやけて見えない。ガラスの上では初代 Liquid の艶のある透明な水滴（屈折・スペキュラのリム・わずかな色収差）が育ち、拍で隣の粒を取り込んで重くなると、拍ごとに少しずつ流れ落ちる。流れた跡だけ曇りが拭われ、そこからロゴがシャープに覗く。水滴の中には背景が倒立して小さく映る。

## タイミング（拍、既定 140 BPM）

| 拍 | 内容 |
| --- | --- |
| 0–3 | 曇ったガラスの向こうで灯りが一つずつ点く |
| 0–16 | 水滴が育ち、拍で合体。5 拍目から重くなった粒が拍ごとに「すっ、すっ」と流れ落ち、蛇行する跡からロゴの断片が見える。いくつかの跡は合流する |
| 16 | 5 小節目の頭。四つのペグ（グロメット）から放射状に曇りが蒸発し始める |
| 20–28 | ホールド：澄んだガラスの奥にくっきりしたロゴ、残った数粒の水滴、玉ボケ。周縁は曇ったまま流れ跡の縞が残る |

全長 28 拍（140 BPM で 12.0 秒）。

**CondensationLoop**（Wide、16 拍 = 4 小節、継ぎ目なし）：解決後の状態。ときどき粒が育って拍で流れ落ち、周縁の曇りを拭い、跡はゆっくり曇り直す。周縁の曇りはループ周期で寄せては引く。`offsetFrames` で開始位置をずらせる（継ぎ目検証用）。

## 技法

- three.js のフルスクリーン・フラグメントシェーダ（`@remotion/three`、swangle ソフトウェア GL で決定的）。
- 背景（玉ボケ＋ロゴ）は 2D canvas に描き、シャープ版と 1/4 解像度でぼかした版の 2 枚をテクスチャとして使う。
- 大きな水滴・流れる水滴は CPU 側で計算した round cone の smooth union（合体時にくびれる）。小さな水滴は 2 層のセルラー（シード付きジッタ）、さらに微細水滴のテクスチャ。
- 流れ跡は、決定的な経路（シード付きノイズで蛇行、拍ごとのサージ）からカプセル列を毎フレーム解析的に生成し、各点の「通過からの経過拍」を持たせる（フィードバックバッファ不要、曇り直しも経過拍で計算）。
- 32px タイルにプリミティブをビニングして、各ピクセルは近くのものだけを評価。

## Props

`bpm`, `liquidColor`（水滴の色味）, `textColor`, `frameColor`, `background`, `fogColor`（曇りの色味）, `warmLight`, `coolLight`（街の灯り）, `lights`（灯りの明るさ）, `fog`（曇りの濃さ）, `logoScale`。Loop は加えて `offsetFrames`。
