# Caustics（コースティクス投影）

## コンセプト
暗闇に浮かぶ小さな水の塊（初代 Liquid のガラス質の水滴：艶・透明感・アクアの色味・明るいリム）。
キックのたびにスピーカーのコーンに載った水のように揺れる。上からの光が水を通り、黒い床に
アクア白のコースティクス（集光の網目）を落とす。網目は次第に整い、小節頭で「ロゴを結ぶレンズ」に
なったかのように光が DAK ロゴ（ヘアラインの枠・4 つのハトメ・Dance at / Kamogawa）へ集まる。
最後は柔らかく揺らめく光の投影として読めるロゴで終わる。

## 技法
- 光の網目は本物の順方向ライト輸送：床上の光線グリッド（560×560 頂点のメッシュ）を水面勾配
  （平面波の和＋キックごとのリング＋光だまり縁の集光）でずらし、三角形ごとの面積比
  （元の面積／着地後の面積、スクリーン微分で計算）を照度として半精度ターゲットに加算描画。
  RGB で屈折率をわずかに変えて 3 回描き、色収差のフリンジを出す。
- ロゴ：ロゴを 2048px マスクにラスタライズし、厳密ユークリッド距離変換で各頂点の最近傍ロゴ点を
  一度だけ計算。「ロゴレンズ」はストローク周囲の帯の光をストローク内側へ折り込む（焦線になる）。
- 最終ホールドは床上にロゴのテクスチャ（#dedede の文字・ヘアライン枠）を重ね、光のゆらぎで変調して可読性を確保。
- 水滴は 3D の変形球をレイマーチ：屈折して床の光を透かし、Beer-Lambert の色、Fresnel で初代のスタジオ環境を反射。
- `useCurrentFrame()` と seeded random のみで決定的（useFrame は描画パスの実行フックとしてのみ使用）。

## タイミング（拍、BPM 140 で 28 拍 = 12 秒）
| 拍 | 内容 |
|---|---|
| 0–2.5 | 光が灯る。斜め上からの視点、水滴の下に小さな光だまり |
| 2.5–12 | 光だまりが広がり、キックごとに網目が揺れる（リング・フォーカスの閃き）。カメラが上昇 |
| 8–15.5 | 波のモードが整列（軸方向・枠を割り切る波長）。12 拍目に一瞬ロゴの気配 |
| 15–16 | 小節頭で光がロゴへ収束 |
| 16–19 | 水滴が落ち着き脇へ、カメラは真上へ |
| 19–28 | ホールド：揺らめく光の投影としてのロゴ |

CausticsLoop（Wide のみ、16 拍）：解決後の状態。毎拍揺れ、2 小節ごとにロゴが部分的に網目へ溶けて小節頭で再結像。
全運動がループ位相の周期関数、`offsetFrames` で開始点をずらして継ぎ目を検証できる。

## Props
`bpm`, `lightColor`（光の色）, `liquidColor`（水滴の色）, `textColor`, `frameColor`, `background`, `logoScale`, `jiggle`（揺れの強さ 0–2）。
CausticsLoop は加えて `offsetFrames`。
