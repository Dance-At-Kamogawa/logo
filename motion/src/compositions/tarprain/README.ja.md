# TarpRain — シートの上の雨粒

## コンセプト
夜、鴨川の河原に敷いたブルーシートを真上から見下ろす。照明はわずかな光だまりだけで、シートのしわと織り目がうっすら光る程度（画面の大半は暗いまま）。
ビートに合わせて雨が落ち、小さなクラウン（ごく小さな飛沫）を立てて、撥水するシートの上でガラス玉のような水滴に分かれる。水滴は転がり、引っかかりながら進み、ロゴの線（フレーム、文字）に引き寄せられて吸い込まれ、線に沿って水が伸びていく。いくつかは外れてシートの上に残る。
バーの頭で最後の水滴がそろって収まり、乾いていた部分が一気に濡れ、4つのハトメに雨粒が落ちて小さな水たまりになる。ロゴが「水で書かれた」状態で、ライトグレーの文字が水の下に浮かび上がって読める。

水滴の質感は最初の Liquid（フライヤー由来のガラスの水滴：屈折と色にじみ、明るいスペキュラ、アクアの色味）を引き継いでいる。

## タイミング（拍、BPM 140 で 1 拍 ≈ 25.7 フレーム）
| 拍 | 内容 |
|---|---|
| 0–1 | 暗いシートだけ |
| 1–15 | 雨（小節ごとに密度が上がる：4分 → 8分 → 16分）。水滴が転がってロゴの線に集まる |
| 14–16 | 最後の水滴群が 16 拍目ちょうどに到着するよう転がる |
| 16 | 5小節目の頭：残りが一斉に濡れ、ハトメに4滴、水たまりが広がる。文字のグレーが 15.5–18 拍でフェードイン |
| 16–26 | ホールド：ロゴが読める状態。文字の外側にだけ雨が降り続け、光がゆっくり揺れて水がきらめく |

全長 26 拍（BPM 140 で 669 フレーム ≈ 11.1 秒）。

## コンポジション
- `TarpRain-Square`（1080×1080）、`TarpRain-Wide`（1920×1080）、60 fps
- `TarpRainLoop-Wide`（1920×1080）：解決後の状態のシームレスな 4 小節ループ。雨はビートで降り続け、水滴は線や休んでいる水滴に吸収され、ときどき線から水滴が抜け出して別の線へ移る。`offsetFrames` でループ開始位置をずらせる（frame 0 == 最終フレーム+1）。

## 仕組み
- ロゴの「濡れる形」（Kamogawa は少し太らせ、細い Dance at は水の線として太らせ、フレームは細い水の線、ハトメは円形の水たまり）を 2D キャンバスに描き、JS で符号付き距離場（Felzenszwalb の EDT）を一度だけ計算（`field.ts`）。
- 雨の計画（`plan.ts`）はシード付き乱数で一度だけ決める：各水滴の行き先は「まだ乾いている線上の点」を貪欲に選び、到着後に水が線（連結成分内）に沿って体積ぶんだけ広がる。その到着時刻を距離場と一緒に float テクスチャに焼き込む。
- シェーダー（`shader.ts`）：距離場を現在の拍で切り取った水の線と、解析的な水滴・クラウンを smooth union し、高さ→法線→屈折・反射・スペキュラ・影で描く。プリミティブは 32px タイルに振り分けて計算量を抑える。
- すべて `useCurrentFrame()` とシード付き乱数から決まる（決定的）。
