# DropLens（雫レンズ）

## コンセプト
黒い空間に、ガラスの雫がいくつか（6 粒）ゆっくり漂う。DAK ロゴは雫の奥の平面にあるが、黒の上では見えず、**雫を通したときだけ**見える。雫は球レンズとして振る舞い、ロゴの断片を拡大・上下左右反転し、縁に色収差のにじみとスペキュラーの光を帯びる。雫は時々触れ合って一瞬くびれでつながり、また離れる。
小節頭（16 拍目）で 4 粒がペグ（グロメット）の位置に落ち着き、ガラスのビーズになる。ビーズは平面に接するので像は焦点を通過して正立に反転し、下のリングを拡大して見せる。同時にビーズからロゴ平面がやわらかく明るくなり、読みやすいロゴのホールドへ。
質感は初代 Liquid（b8bc464）の雫（アクアの吸収、ミルキーな散乱、裏側のコースティクス、スタジオ照明の反射、鋭いグリント）を踏襲。

## タイミング（拍、bpm 140 で 1 拍 ≈ 25.7 f）
- 0–8: 雫が一粒ずつ現れ、ロゴの断片をなぞる
- 〜8–11: 雫同士がかすめて一瞬つながる（メタボール）
- 12–16: 4 粒がペグへ向かい、16 拍目（小節頭）に着地。像が焦点を通って正立へ
- 16–20: ビーズからロゴ平面がワイプ＋ブルームで点灯
- 16–28: ホールド。ビーズが拍ごとに角を一周するように光り、2 粒の自由な雫がロゴの上を漂う（＝ DropLensLoop）
- 全長 28 拍（12.0 s）

## コンポジション
- `DropLens-Square`（1080×1080）、`DropLens-Wide`（1920×1080）、60 fps
- `DropLensLoop-Wide`：解決後の状態の 4 小節シームレスループ（全運動がループ位相の周期関数、frame 0 == 最終+1）

## Props
`bpm`（140）、`glassColor`（#6fd3cd）、`textColor`（#dedede）、`frameColor`（#b0b0b0）、`background`（#000000）、`logoScale`（0.62）、ループのみ `offsetFrames`（シーム確認用）

## 出力（`pnpm render --only=droplens`）
- `dak-droplens-1080x1080.mp4`、`dak-droplens-1920x1080.mp4`
- `dak-droplens-loop-1920x1080.mp4` と `dak-droplens-loop-1920x1080-hap.mov`（HAP Q、ProRes 422 HQ マスターから）

## 技術メモ
全画面フラグメントシェーダー（`@remotion/three`）。雫は円のスムーズユニオン（距離場）で、球冠の高さ場から法線を作り、各ピクセルを仮想球レンズで追跡（前面で屈折→背面で屈折→ロゴ平面に当たる）。屈折率を 3 つ使い色収差を出す。ロゴ平面は 2048px のキャンバスに一度だけ描き、ミップマップ付きで使い回す。`useCurrentFrame()` とシード付きノイズのみで決定的。
